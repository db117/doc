# 云端同步采用记录级合并与每日快照

个人净资产追踪器继续以浏览器本地账本为主数据，并为 OneDrive 与 Google Drive 提供用户手动触发的备份、云端覆盖本地和合并同步。合并以账户、月度余额、月度汇率和分期项目为独立单元，采用最后修改版本，时间相同时云端获胜；单边记录保留，删除只通过本地备份覆盖云端传播。这避免引入删除墓碑、逐条冲突界面、后台令牌和三方云端合并，同时优先防止财务数据丢失。

本地账本每次成功变更都覆盖当天 IndexedDB 快照，云端账本内容实际变化时覆盖当天 `history/YYYY/` 快照；每日最多一份，按执行设备本地日期永久保留。历史恢复只覆盖本地并保留回退，用户确认后再主动备份到云端。

## Consequences

- 设备时钟需要基本准确；相同时间戳冲突固定采用云端版本。
- 合并不传播删除，用户必须使用“备份到云端”明确发布删除结果。
- 本地写入成功但云端失败时保留本地结果并允许重试，不伪装成跨系统原子事务。
- Google Drive 使用可见的“个人净资产追踪”目录；两个云端都保存 `README.txt`、当前账本和按年份组织的每日历史。
