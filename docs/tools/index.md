# 在线工具

- [美股期权策略构建器](./options-strategy.md)：读取本地富途行情，构建单到期日期权组合并交互分析理论盈亏。
- [美股期权 3D 波动率曲面](./options-volatility-surface.md)：读取本地富途多期限期权链，查看行权价、期限和隐含波动率的三维关系。
- [个人净资产追踪](./net-worth.md)：在浏览器本地更新资产、负债和分期账户，并查看最新净资产。
- [个人净资产追踪使用指南](./net-worth-guide.md)：新增和更新账户，管理外币、分期负债与本地、OneDrive 或 Google Drive 备份。
- [OpenD 在线工具本地使用指南](./options-strategy-local-setup.md)：安装并登录 Futu OpenD，启动本地 Bridge，并完成期权工具连接。
- [V2Ray 转 Clash 订阅](./v2ray-to-clash.md)：在浏览器本地把 V2Ray 订阅转换为 Clash Verge Rev 可用的 Mihomo YAML。
