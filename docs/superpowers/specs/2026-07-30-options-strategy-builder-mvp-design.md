# 美股期权策略构建器 MVP 设计

## 目标

在文档站新增 `/tools/options-strategy`，提供一个只读的美股期权策略构建器。用户从本地 `futu_bridge` 获取股票、ETF、到期日和期权链，通过点击报价组成假设策略，并使用可拖动的日期、IV 与盈亏图分析风险收益。

页面不连接交易账户，不下单，也不把策略解释为真实订单或持仓。

## MVP 范围

包含：

- 搜索并选择美股或美股 ETF，默认 `US.MU`。
- 选择一个期权到期日。
- 显示完整 T 型期权链，Call 在左、Put 在右。
- 点击 Ask 买入一张，点击 Bid 卖出一张。
- 编辑策略腿净数量和建仓参考价。
- 计算净支出或净收入、最大盈利、最大亏损和盈亏平衡点。
- 显示可缩放、平移并带游标的理论盈亏图。
- 拖动情景日期、情景 IV 和图表范围。
- 每五秒刷新行情，支持手动刷新和过期行情提示。
- 支持 VitePress 明暗主题和键盘操作。

不包含：

- 下单、改单、撤单或任何交易上下文。
- 港股、指数、期货期权、非标准调整合约和跨到期日组合。
- 策略推荐、预设策略、自动命名、历史回测和波动率曲面。
- 策略保存、分享链接、账户持仓导入和交易费用设置。
- 分红数据接入；MVP 的分红收益率固定为零。

## 架构

- 页面和 Vue/TypeScript 代码位于 `doc` 仓库。
- OpenD 与 Python SDK 集成继续位于 `trade-ai/futu_bridge`。
- 浏览器默认请求 `http://127.0.0.1:8765`，允许修改 Bridge Base URL，并保存到 `localStorage`。
- 页面只调用 Bridge 的只读 GET 接口。
- 期权定价、组合计算、状态变更和图表展示分成独立模块。

页面使用以下接口：

```text
GET /health
GET /api/stocks?market=US&type=STOCK
GET /api/stocks?market=US&type=ETF
GET /api/option-expirations?symbol=US.MU
GET /api/option-chain?symbol=US.MU&expiry=2026-08-03
```

股票和 ETF 列表并行获取、合并并在页面会话中缓存。期权链响应中的 IV 是百分数，进入计算模块前统一转换为小数。

## 页面布局

页面采用工具工作台布局，不使用普通文档正文宽度。

- 顶部工具栏：标的搜索、到期日、连接状态、最后更新时间、刷新和连接设置。
- 桌面端左侧约 60%：T 型期权链。
- 桌面端右侧约 40%：到期统计、策略腿、盈亏图和滑块，并在滚动期权链时保持可见。
- 小于约 `1100px` 时改成上下布局，分析区位于期权链上方。
- 延续 VitePress 现有青绿色品牌变量和系统字体，不另建金融终端风格主题。

## T 型期权链

默认列为：

```text
Vega / Theta / Gamma / Delta / 成交量 / 持仓量 / IV / 最新价 / Ask / Bid
｜行权价｜
Bid / Ask / 最新价 / IV / 持仓量 / 成交量 / Delta / Gamma / Theta / Vega
```

- Call 在左，Put 在右，行权价中轴保持醒目。
- 插入当前标的价格提示，并用浅色区分价内区域。
- Bid/Ask 缺失或不大于零时显示 `—`，且不可点击。
- 使用固定行高的虚拟滚动展示全部行权价，不截断合约列表。
- 首次加载和切换到期日后定位到最接近现价的行权价，并提供“跳转到现价”。
- 长仓在 Ask 侧显示净数量状态，短仓在 Bid 侧显示净数量状态。

## 策略状态与交互

每个合约代码最多对应一条策略腿，使用有符号净数量：正数为买入，负数为卖出。

- 点击 Ask：净数量增加 1，以当时 Ask 作为本次建仓参考价。
- 点击 Bid：净数量减少 1，以当时 Bid 作为本次建仓参考价。
- 同方向增加数量时按数量计算加权平均建仓参考价。
- 反方向点击先抵消已有数量；净数量为零时删除策略腿。
- 策略腿列表允许直接修改净数量和建仓参考价，也允许单腿删除和清空组合。
- 行情刷新只更新报价、Greeks 和基础 IV，不修改建仓参考价。
- 切换标的或到期日时，空策略直接切换；非空策略先确认，确认后清空全部策略腿。

合约乘数优先使用 `contract_size`，其次使用 `lot_size`。两者都无效时，美股标准期权按 100 估算并显示提示。

## 计算规则

### 现金流与盈亏

设策略腿净数量为 `q`，建仓参考价为 `entry`，理论价值为 `value`，合约乘数为 `multiplier`：

```text
建仓净成本 = Σ(q × entry × multiplier)
理论盈亏 = Σ(q × (value - entry) × multiplier)
```

建仓净成本大于零显示为净支出，小于零显示为净收入。全部结果为税费前口径，并标注“未计交易费用”。

### 到期统计

到期时 Call 和 Put 的价值分别为：

```text
Call = max(标的价格 - 行权价, 0)
Put  = max(行权价 - 标的价格, 0)
```

最大盈利、最大亏损和盈亏平衡点从同到期日组合的分段线性到期盈亏函数计算。检查价格零点、全部行权价和无穷远尾部斜率；尾部没有有限边界时显示“无限”。顶部到期统计不随日期和 IV 滑块改变。

### 到期前理论价值

使用 Bjerksund–Stensland 2002 美式期权近似模型，与当前 OptionStrat 的公开客户端行为保持一致。

- 无风险利率作为页面级配置，MVP 默认年化 `4.5%`。
- 分红收益率固定为 `0`，持有成本使用 `r - q`。
- 剩余期限按情景时点到到期时点的实际秒数除以 365 天计算。
- 到期日不调用模型，直接使用内在价值。
- 页面显示“理论估算”，并说明未计未来分红。

## IV 规则

- 平值 IV 取最接近现价的行权价；Call 和 Put IV 都有效时取平均值，只有一侧有效时使用该侧。
- IV 滑块显示所选到期日的情景平值 IV。
- 有效 IV 倍率为 `情景平值 IV / 当前平值 IV`。
- 每条腿使用自身市场 IV 乘以该倍率，从而保留波动率微笑。
- 某条腿缺失 IV 时，先回退到当前平值 IV，再应用倍率。
- 整个到期日没有可用 IV 时，只显示到期盈亏，禁用到期前日期和 IV 模拟并解释原因。

## 盈亏图

使用按需引入的 ECharts 折线图、Tooltip、DataZoom 和 CanvasRenderer。

- 默认情景日期为到期日，默认 IV 为当前平值 IV。
- 日期滑块覆盖当前时间至到期时间。
- 横轴默认以当前标的价格为中心显示 `±12%`，范围滑块为 `±5%` 至 `±100%`。
- 图表支持拖动平移、滚轮和触控缩放、十字游标与恢复默认范围。
- Tooltip 显示标的价格和当前情景下的税费前理论盈亏。
- 盈利区域使用克制的绿色，亏损区域使用红色，并显示零盈亏线、现价线和盈亏平衡点。
- 滑块连续拖动时用 `requestAnimationFrame` 合并重算和绘图更新。

## 行情刷新与页面状态

- 页面可见时每五秒刷新期权链。
- 页面隐藏时暂停；恢复可见时立即刷新。
- 手动刷新与自动刷新共享同一请求，避免并发覆盖。
- 首次加载使用表格骨架屏。
- Bridge 无法连接时保留页面框架，提供“重新连接”和“连接设置”。
- OpenD 查询失败时显示服务错误，但不清空策略。
- 自动刷新失败时保留最后成功行情并标记“数据已过期”。
- 无期权、无到期日和无合约分别提供可操作的空状态。

## 验证标准

- Bjerksund–Stensland 2002 使用公开参考值覆盖 Call、Put、到期和零波动边界测试。
- 策略状态测试覆盖同向加仓加权平均、反向抵消、归零删除和直接编辑。
- 到期统计测试覆盖单腿、垂直价差、跨式、铁蝶、无限盈利和无限亏损。
- Bridge 客户端测试覆盖成功、缺失字段、超时、错误响应和过期行情。
- 组件测试覆盖 Bid/Ask 点击、切换确认、刷新保留成本和无 IV 降级。
- 运行 `npm test` 与 `npm run docs:build`。
- 本地启动页面后，在明暗主题和桌面、窄屏布局下进行浏览器视觉检查。
